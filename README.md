# Claude Skills Repository

A collection of custom Claude skills for productivity, content creation, faith documentation, and technical education.

## 📚 Skills Directory

### 1. **jonnytech-article-designer**

Convert technical articles, blog posts, and news into beginner-friendly JonnyTech posts. Use this skill whenever someone asks to simplify an article, convert a blog post, or explain technical content. The skill breaks down complex topics into short sentences, plain language, and real-world analogies so anyone can understand — regardless of tech level. Triggers include phrases like "Simplify this article for JonnyTech," "Convert this into a JonnyTech post," or "Explain this blog post."

## 🚀 How to Use

1. Download a `.skill` file
2. Install in Claude.ai settings
3. Use the trigger phrases
